# KSS Innovate Website

This is the codebase for the KSS Innovate website - a professional software solutions and web development services company.

## 🌐 Live Website
https://kss-innovate.netlify.app/

## 📱 Features

### Responsive Design
- ✅ Fully responsive across all devices (mobile, tablet, desktop)
- ✅ Mobile hamburger navigation menu
- ✅ Adaptive layouts for screen sizes 375px and above
- ✅ Touch-optimized interface for mobile users

### Key Sections
- **Hero Section** - Eye-catching intro with call-to-action
- **Services** - Showcase of development and design services
- **Projects** - Display of recent work and case studies
- **Pricing** - Flexible pricing packages with toggle (monthly/yearly)
- **About** - Company information and mission
- **Contact** - Email form with validation

## 🛠️ Technologies Used
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Bootstrap**: 5.0.2 (for component framework)
- **Email Service**: EmailJS
- **Hosting**: Netlify (auto-deployed from GitHub)
